# Phase69 報告: stabilityの減点構造を実測で把握(事実収集、仮説なし)

## 前置き

本フェーズは仮説を立てずに事実だけを集める指示だったため、**「原因はこれだ」という
結論は書かない。** 以下は全て2G(振幅19.6m/s²、公式開示レンジ1〜3Gの中央)・
28シーン(26 suite + sample_config 2タスク)の実測値であり、本番のstability_score

`tools/scorer.py`・`tools/diagnose_stability.py`・`src/`・既存configはいずれも変更していない。

## (1-1) disp/energy内訳(28シーン平均)

| 指標 | 平均 | σ |
|---|---:|---:|
| stability_score | 85.46 | 4.53 |
| disp_score | 79.69 | 5.30 |
| energy_score | 98.94 | 4.96 |

`stability = 0.7·disp_score + 0.3·energy_score`なので、100点からの減点(平均14.54pt)を
disp由来/energy由来に分解すると:

| 内訳 | 減点(平均) | 全体に占める割合 |
|---|---:|---:|
| disp由来(0.7×(100−disp_score)) | 14.22pt | **98.9%** |
| energy由来(0.3×(100−energy_score)) | 0.32pt | 1.1% |

**2Gでも energy_score はほぼ100のまま(平均98.94)。** Phase52が0.6Gで確認した
「energyはほぼ100」という状態は2Gでもほとんど変わっていない。**減点はほぼ全量が
disp(変位)側で発生している。**

(参考: この28シーン平均stability=85.46は、Phase67の対照設定・2G・28シーンの
実測値85.47とほぼ完全に一致しており、測定方法の一貫性が確認できる。)

## (1-2) 荷物単位の変位分布

全28シーンの荷物をプールした結果(n=718):

| 指標 | 値 |
|---|---:|
| disp平均 | 0.0614m |
| disp中央値 | 0.0529m |
| disp最大 | 0.5882m |
| disp標準偏差 | 0.0484m |
| disp > 0.05m の荷物数 | 396/718(55.2%) |
| disp > 0.10m の荷物数 | 113/718(15.7%) |
| disp > 平均+2σ の荷物数 | 23/718(3.2%) |
| **上位10%(n=71)の荷物が占める変位合計の割合** | **26.3%** |
| 上位1%(n=7)の荷物が占める変位合計の割合 | 5.1% |

**上位10%は「公平な取り分」(10%)の2.6倍の変位を占めるが、支配的というほどではない。**
一方で**718件中396件(55.2%)が5cm超動いており、「動いているのはごく一部」とは
言えない規模**である。上位1%(7件)の取り分は5.1%とかろうじて比例(1%)を超える程度で、
極端な外れ値が全体を支配している様子はない。

### 大きく動いた荷物(上位10%, n=71) vs 残り(n=647)の属性差

| 属性 | 上位10%平均 | 残り90%平均 | 差 |
|---|---:|---:|---:|
| mass | 3.34 | 3.73 | −0.40 |
| length | 0.550 | 0.490 | +0.060 |
| width | 0.517 | 0.481 | +0.036 |

| is_prioritized(比率) | 38.0% | 15.5% | +22.6pt |
| order_frac_in_container(0=最初,1=最後) | 0.515 | 0.498 | +0.017 |
| n_items_in_container | 18.0 | 21.2 | −3.1 |
| **world_z(重心高さ)** | **0.964** | **0.586** | **+0.377** |
| dist_to_door | 0.953 | 0.783 | +0.169 |
| n_support_items(支えている荷物数) | 0.676 | 0.453 | +0.223 |
| **on_floor_or_shelf(床/棚に直接接触、比率)** | **12.7%** | **38.3%** | **−25.7pt** |

**最も差が大きいのは高さ(world_z)と「床/棚に直接接触しているか」。** 大きく動いた

高いが、これは単に優先荷物がより高い位置・より攻めた配置に置かれやすいことの
反映である可能性があり、この時点でどちらが原因かは分からない。

## (1-3) 位置・支持との相関(Pearson r、全荷物プールn=718)

| 変位量との相関対象 | r |
|---|---:|
| **重心高さ(world_z)** | **+0.405** |
| 床/棚に直接接触(0/1) | −0.190 |
| 支えている荷物数(n_support_items) | +0.183 |
| コンテナ内配置順(0=最初,1=最後) | +0.164 |
| is_prioritized(0/1) | +0.126 |
| is_soft(0/1) | −0.124 |
| 接地面積比(凸包近似) | +0.083 |
| **扉(搬入口)からの距離** | **+0.060** |
| 底面接触点数 | +0.026 |
| 質量 | −0.015 |

**実測で最も強い相関は重心の高さ(r=+0.405、中程度の正の相関)。** 他は軒並み
弱い(|r|<0.2)。**「扉付近(手前)かどうか」との相関はr=+0.060とほぼゼロ**——
公式が名指しした「入り口付近の荷物」の懸念は、少なくとも変位の大きさそのものとは
今回の測定では結びつかなかった(扉に近いか遠いかで変位量に系統的な差は見えない)。
支持の質(支えている荷物数・接地面積比・接触点数)もいずれも弱い相関に留まる。

なお接地面積比(凸包近似)は底面接触点が2点以下だと定義上0になる荷物が一定数あり
(2点接触ではボックス-ボックス接触の凸包が面積を持たない)、この指標自体の
分解能に限界がある点は留意する必要がある。

## (1-4) シーン単位の傾向

28シーンをstability昇順で並べた一覧は`results/phase69_analysis_summary.json`に
保存した。シーン単位の相関(n=28):

| 相関対象 | r |
|---|---:|
| stability vs mean_disp(シーン平均変位) | −0.954 |
| stability vs max_disp(シーン最大変位) | −0.900 |
| **stability vs 上位10%変位シェア** | **−0.521** |
| stability vs n_items(シーン内荷物数) | −0.025 |
| **stability vs cog_score** | **+0.128** |
| cog_score vs 上位10%変位シェア | −0.187 |

**stability vs mean_disp/max_dispの強い負相関(r=−0.95/−0.90)は、disp_scoreが
mean_dispから直接計算される式である以上、ほぼ定義どおりの結果**であり新情報ではない。
一方、**「上位10%変位シェア」とstabilityの相関はr=−0.521(中程度)**——変位が
少数に偏って集中しているシーンほどstabilityが低い傾向はあるが、完全に一致するわけ
ではない(例: `suite_A02`はシェア10.3%と最も低い部類だがstability=83.14と中位)。

**stability低位7シーン**: B02(71.02)、A05(73.22)、C02(81.66)、A04(82.66)、
D04(82.77)、A02(83.14)、D03(83.39)。
**stability高位7シーン**: D05(91.59)、P02(90.83)、D01(89.96)、A07(89.30)、
C01(89.29)、B04(88.89)、P04(88.63)。

### cog_scoreとの関係(実測)

**シーン単位のcog-stability相関はr=+0.128と弱い。** cog_scoreは
「100×(1−質量加重重心高さの正規化値)」で定義され、**値が高いほど重心が低い
(良い)ことを意味する**(`tools/scorer.py::calculate_cog_score`)。

実測データにはこの弱い相関を裏付ける反例がある: **stabilityが最も高いシーン
D05(91.59)は、cog_scoreが50.74と28シーン中最も低い(=重心が最も高い)部類に入る。**
逆に、stabilityが最も低いシーンB02(71.02)のcog_score(63.45)は28シーン中の
中位で、最下位ではない。**「重心を下げればstabilityも上がる」という関係は、
この28シーンのローカル実測では強くは成立していない。**

## (2) 事実の整理

### (2-1) 読み取れる事実(提案は含まない)

1. 2Gでのstability減点は**98.9%がdisp(変位)由来**で、energy由来は1.1%にすぎない。
   energy_scoreは2Gでも0.6G相当とほぼ変わらず100近傍のまま。
2. 荷物単位の変位は「少数の極端な外れ値」ではなく、**718件中55.2%が5cm超動く
   広範な現象**。上位10%の取り分は26.3%(公平配分の2.6倍)で、集中はあるが
   支配的ではない。
3. 属性差で最も大きいのは**重心の高さ**(上位10%movers平均0.96m vs 残り0.59m)と
   **「床/棚に直置きされているか」**(上位10%moversは12.7%のみが直置き、残りは
   38.3%が直置き=moversは他の荷物の上に積まれている比率が高い)。
4. 全荷物プールでの相関は、**高さ(r=+0.405)が最も強く**、それ以外
   (扉からの距離r=+0.060、支持の質r=+0.18程度以下)はいずれも弱い。
5. シーン単位では、変位の集中度(上位10%シェア)とstabilityに中程度の負の相関
   (r=−0.521)があるが、例外(A02)も存在する。
6. cog_scoreとstability_scoreのシーン単位相関はr=+0.128と弱く、**両者が同じ
   方向に動くという関係は今回のローカル実測では強くは支持されない**。最高
   stabilityシーン(D05)が最低cog_score層に属するという反例が存在する。

### (2-2) 「少数が引き下げているか」「全体が一様に動いているか」

**どちらか一方ではなく、その中間に近い。** 上位10%が公平配分の2.6倍を占める
という点では偏りがあるが、718件中55.2%が5cm超動いているという点では
「ごく少数だけが動き、残りはほぼ静止している」とは言えない。**広い母集団が
底上げ的に動いた上に、やや偏った上乗せがある、という構造**が実測から読み取れる
事実である。

### (2-3) cogとstabilityは同じ方向に動くか

**実測では、シーン単位の相関はr=+0.128であり、強い同方向の関係は確認できなかった。**
明確な反例(D05: 最低cog層で最高stability)も存在する。この結果だけからは
「1つの施策で3/7が同時に動く」とも「トレードオフになる」とも断定できず、
**弱い正の相関はあるが、それだけでは施策設計の根拠にできるほど強くない**、
というのが実測から言える範囲である。
